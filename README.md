# 💰 MoneyMate | 

**MoneyMate** یک وب‌اپلیکیشن رایگان، فارسی و واکنش‌گرا برای مدیریت درآمد، هزینه و بودجه شخصی است. این پروژه در چارچوب تمرین «ساخت وب‌اپلیکیشن با AI و Vibe Coding» و با کمک ChatGPT تولید و آزمایش شده است.

## امکانات

- داشبورد مالی با مانده کل، درآمد، هزینه و پس‌انداز ماهانه
- ثبت، ویرایش و حذف درآمد و هزینه با دسته‌بندی و یادداشت
- فیلتر تراکنش‌ها بر اساس نوع و دسته‌بندی، جست‌وجو و مرتب‌سازی
- نمودار درآمد و هزینه در شش ماه گذشته، و نمودار سهم دسته‌های هزینه
- بودجه ماهانه قابل تنظیم، نوار پیشرفت و هشدار عبور از سقف
- تغییر ماه و گزارش ماهانه، خروجی CSV قابل بازکردن در Excel
- حالت روشن و تاریک، نمایش ریسپانسیو روی موبایل و کامپیوتر
- داده آزمایشی قابل بارگذاری و حذف با یک کلیک
- ذخیره‌سازی محلی از طریق `localStorage` (بدون سرور، اشتراک یا API پولی)

## معماری پروژه

```
MoneyMate/
├── index.html       ← ساختار و اطلاعات سایت
├── styles.css       ← طراحی واکنش‌گرا و حالت تاریک
├── app.js           ← منطق تراکنش‌ها، نمودارها، بودجه و ذخیره‌سازی
├── favicon.svg      ← نماد برنامه
├── README.md        ← همین راهنما
├── PROMPTS.md       ← پرامپت‌های مستند برای ارائه
└── TEST_REPORT.md   ← گزارش تست‌ها
```

**فناوری‌ها:** HTML5، CSS3، JavaScript خالص (Vanilla JS)، SVG، `localStorage` و AI برای تولید کد. برای اجرای پروژه نیازی به npm، Node.js، نصب پکیج، سرور اختصاصی یا API نیست. فونت Vazirmatn در صورت دسترسی از Google Fonts بارگذاری می‌شود؛ در غیر این صورت فونت جایگزین سیستم نمایش داده می‌شود.

## اجرا روی رایانه

فایل `index.html` را در مرورگر باز کنید. می‌توانید برای نمایش بهتر، فایل‌های پروژه را از طریق یک وب‌سرور ساده هم اجرا کنید (اختیاری):

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید. **تنها یک پوشه حاوی همه فایل‌ها کافی است.**

## مراحل انتشار رایگان

### ۱. GitHub

1. وارد [github.com/new](https://github.com/new) شوید و یک مخزن عمومی با نام `moneymate` ایجاد کنید. اگر مخزن خالی می‌خواهید، گزینه ساخت README را تیک نزنید.
2. فایل ZIP دریافتی را روی رایانه **Extract / Unzip** کنید.
3. وارد مخزن شوید و گزینه **uploading an existing file** یا **Add file → Upload files** را بزنید.
4. **تمام فایل‌های داخل پوشه MoneyMate** را انتخاب و آپلود کنید. مهم است `index.html` در **ریشه مخزن** باشد، نه در پوشه‌ای تو در تو. خود ZIP را در مخزن آپلود نکنید.
5. روی **Commit changes** کلیک کنید.

### ۲. Vercel

1. به [vercel.com/new](https://vercel.com/new) بروید و با GitHub وارد شوید.
2. مخزن `moneymate` را در **Import Git Repository** انتخاب کنید.
3. تنظیمات: **Framework Preset = Other**، **Root Directory = `./`**، **Build Command = خالی** (در صورت نیاز Override را روشن کنید)، **Output Directory = `.`** یا مقدار پیش‌فرض مربوط به فایل‌های ایستا.
4. **Deploy** را بزنید. آدرس `*.vercel.app` که Vercel نمایش می‌دهد، لینک تحویل پروژه است.

روش جایگزین: برای انتشار اولیه بدون اتصال GitHub، می‌توانید فایل ZIP را در [Vercel Drop](https://vercel.com/drop) قرار دهید؛ اما برای تکلیف شما **داشتن لینک GitHub هم الزامی است**.

## نحوه استفاده

1. برای بررسی امکانات، روی **نمایش نمونه** کلیک کنید تا چند ماه تراکنش آزمایشی بارگذاری شود.
2. در داشبورد و گزارش‌ها، با فلش‌های کنار ماه، ماه انتخابی را تغییر دهید.
3. برای استفاده واقعی، روی **شروع با حساب خودم** کلیک کنید؛ این عمل پس از تأیید، تراکنش‌های نمونه را پاک می‌کند.
4. با **ثبت تراکنش**، درآمد و هزینه وارد کنید. برای تغییر یا حذف از آیکون‌های کنار تراکنش استفاده کنید.
5. از بخش **بودجه‌بندی**، سقف هزینه را مشخص کنید. این سقف در نسخه فعلی برای تمام ماه‌ها ثابت است؛ هزینه‌ها فقط برای ماه انتخابی محاسبه می‌شوند.
6. از بخش **گزارش‌ها** یا **تراکنش‌ها**، خروجی CSV بگیرید.

## نکات حریم خصوصی و محدودیت‌ها

- اطلاعات کاربر فقط در `localStorage` همان مرورگر/دستگاه ذخیره می‌شود؛ هیچ داده‌ای به سرور یا بانک فرستاده نمی‌شود.
- پاک‌کردن داده‌های سایت یا بازکردن آن در مرورگر/دستگاه دیگر باعث عدم دسترسی به تراکنش‌های قبلی می‌شود؛ قبل از این کار از تراکنش‌ها CSV بگیرید.
- هیچ قابلیت ثبت‌نام، همگام‌سازی چنددستگاهی، اتصال بانکی یا پشتیبان‌گیری ابری وجود ندارد.
- چون داده‌ها فقط در مرورگر ذخیره می‌شوند، برای اطلاعات مالی محرمانه یا حساس باید از شیوه‌های محافظت و پشتیبان‌گیری مناسب استفاده کرد.
- تمامی مبالغ **تومان** هستند؛ تاریخ ورودی و فیلتر ماه بر اساس **تقویم میلادی** است.
- برنامه جهت آموزش و مدیریت شخصی طراحی شده است و مشاوره مالی محسوب نمی‌شود.

## ابزارهای AI

**ChatGPT (OpenAI)** برای ایده‌پردازی، تعیین امکانات، تولید HTML/CSS/JavaScript، اصلاح نمایش اعداد و انجام تست‌های مرورگر به کار رفت. بخش قابل‌استفاده سایت وابستگی اجرایی به سرویس ChatGPT ندارد.

برای سه متن پرامپت مناسب ارائه و شرح مراحل، به فایل `PROMPTS.md` مراجعه کنید. پرامپت‌ها به‌عنوان نمونه‌های بازتولید فرآیند نوشته شده‌اند؛ اگر آن‌ها را در مراحل بعدی استفاده کردید، همان نسخه‌های واقعاً استفاده‌شده را در گزارش نهایی ثبت کنید.
